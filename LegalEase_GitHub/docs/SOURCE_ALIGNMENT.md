# Source Alignment

This repository was prepared from the supplied SmartBridge `LegalEase.pdf` project document.

Key source requirements reflected in this repository:
- LegalEase is an AI-powered legal document generator.
- Streamlit is the frontend.
- FastAPI is the backend.
- Gemini is used for AI generation.
- Inputs include document type, parties, terms and dates.
- Generated content can be edited.
- Output formats include TXT, DOCX and PDF.
- The reference architecture includes frontend, backend, AI core and formatting modules.
- The reference workflow includes model selection, core functionality, API integration, frontend development, deployment/testing and conclusion.

The supplied PDF is 25 pages and includes screenshots of the intended interface, architecture, generated-document output and export formats. The eight phase submission structure comes from the SmartBridge message provided in the chat; the technical implementation details come from the uploaded project document.
