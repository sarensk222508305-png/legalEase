# Phase 4 — Project Planning

## Work Breakdown

| Stage | Tasks | Deliverable |
|---|---|---|
| 1 | Ideation and use cases | Problem/solution definition |
| 2 | Requirements | Functional/non-functional requirements |
| 3 | Architecture | Component/data-flow design |
| 4 | Environment | Python environment and dependencies |
| 5 | Backend | FastAPI + Gemini integration |
| 6 | Frontend | Streamlit UI |
| 7 | Export | TXT/DOCX/PDF |
| 8 | Testing | Test cases and validation |
| 9 | Documentation | README + phase documents |
| 10 | Demonstration | Demo video and submission checklist |

## Suggested Team Roles
For a 2–5 member student team:
- Member 1: Backend/API
- Member 2: Frontend/UI
- Member 3: AI integration/document formatting
- Member 4: Testing/documentation
- Member 5: Demo/deployment support

Roles can be combined for smaller teams.

## Milestones
- Milestone 1: Model selection and architecture
- Milestone 2: Core functionality
- Milestone 3: API logic integration
- Milestone 4: Frontend development
- Milestone 5: Local deployment and testing
