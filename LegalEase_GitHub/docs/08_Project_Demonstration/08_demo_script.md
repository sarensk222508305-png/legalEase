# Phase 8 — Project Demonstration

## Recommended Demo Flow

### 1. Introduction
Say:
> “Hello everyone. Our project is LegalEase, an AI-powered legal document generator. It helps users create structured legal-document drafts from a few simple inputs.”

### 2. Purpose
Explain that the project is intended to simplify creation of customizable, editable legal-document drafts for users without a legal background.

### 3. Show the Interface
Display:
- LegalEase title
- Document type
- Parties
- Terms & Conditions
- Effective date
- Generate button

### 4. Enter Demo Data
Use:
- Document Type: Freelance Work Contract
- Parties: Jane Doe (Service Provider), TechNova Inc. (Client)
- Terms: Payment within 30 days; Confidentiality must be maintained; Either party may terminate with 15 days notice
- Effective Date: April 15, 2025

### 5. Generate
Click **Generate Document** and show the generated result.

### 6. Explain the Workflow
Explain:
> “The Streamlit frontend sends the inputs to the FastAPI backend. The backend validates the request and passes it to the Gemini document generator. The generated text is returned to the frontend, where it can be reviewed and edited.”

### 7. Edit
Change one sentence in the editable document area and show the updated preview.

### 8. Download
Demonstrate:
- TXT
- DOCX
- PDF

Open one exported file to show formatting.

### 9. Benefits
Mention:
- Faster drafting workflow
- Editable output
- Multiple export formats
- Simple user interface
- AI-assisted document generation

### 10. Closing
> “This concludes our demonstration of LegalEase. The system is an academic prototype and generated documents should be reviewed by a qualified legal professional before real-world use.”
